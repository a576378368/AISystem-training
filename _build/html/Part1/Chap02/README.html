本章小结#

本章系统介绍了Python编程的基础知识，为后续学习AI系统打下坚实基础。

Python基础语法部分涵盖了变量与数据类型（整数、浮点、字符串、布尔值）、控制流语句（if/for/while）以及函数的定义与调用，包括参数类型、返回值和作用域等核心概念。

面向对象编程部分讲解了类与对象的概念、封装（私有属性）、继承（子类化）和多态（统一接口），以及实例方法、类方法和静态方法的区别。

Python高级特性部分介绍了列表推导式、生成器与迭代器（惰性求值节省内存）、装饰器（修改函数行为）以及上下文管理器（资源管理）。

NumPy基础部分详细讲解了ndarray数组的创建（从列表、预定义、范围、随机）、属性（shape、dtype、ndim）、索引与切片、形状操作（reshape、transpose、连接分割），以及逐元素运算、矩阵运算及核心的广播机制。

PyTorch基础部分介绍了Tensor的创建与操作、自动求导机制（autograd）、神经网络的构建方法（Sequential和类继承）、常用层和激活函数、损失函数与优化器，以及完整的数据加载和训练流程。

通过本章学习，读者将掌握Python编程的核心技能，理解NumPy的高性能数组操作，并具备使用PyTorch构建简单深度学习模型的能力。

思考与练习#

  1. Python基础：编写一个函数，接受一个整数列表，返回其中所有奇数的和。例如，输入 [1, 2, 3, 4, 5]，输出 9（1+3+5）。

  2. 面向对象：创建一个 Rectangle 类，包含 width 和 height 属性，以及计算面积和周长的方法。添加属性验证，确保宽高为正数。

  3. NumPy：创建一个 5×5 的矩阵，元素为 1 到 25 的整数，然后提取主对角线元素、提取上三角部分、计算矩阵的转置。

  4. PyTorch：实现一个简单的多层感知机（MLP），包含两个隐藏层（每层128个神经元），用于对MNIST手写数字进行分类（10类）。使用ReLU激活函数，输出层使用LogSoftmax。

  5. 综合应用：使用PyTorch实现一个学习率调度器，在训练过程中根据epoch数动态调整学习率：前5个epoch使用固定学习率0.01，之后每个epoch将学习率衰减为原来的一半。
