本章小结#

本章系统介绍了人工智能数学基础的三大核心领域：线性代数、概率论与统计学、以及优化理论。

线性代数基础章节涵盖向量与矩阵的基本概念与运算、行列式与逆矩阵的计算、特征值与特征向量的意义，以及矩阵分解（SVD、LU分解等）和范数理论。这些知识是理解神经网络数据表示和计算的基础。

概率与统计章节从概率的公理化定义出发，深入讲解了条件概率、贝叶斯定理等核心理论，介绍了离散和连续随机变量及其常见分布（伯努利分布、正态分布、指数分布等），并讨论了大数定律和中心极限定理等统计基础。这些知识为理解机器学习的概率模型和统计推断提供了理论支撑。

优化基础章节介绍了优化问题的基本概念，重点讲解了梯度下降法和随机梯度下降法的原理与收敛性分析，并详细介绍了动量法、Adam、RMSprop等高级优化算法。最后探讨了约束优化问题的拉格朗日乘数法和KKT条件。这些优化技术是训练神经网络的核心工具。

思考与练习#

线性代数#

  1. 向量运算验证：设 \(\vec{a} = (1, 2, 3)\)，\(\vec{b} = (4, 5, 6)\)，计算 \(\vec{a} + \vec{b}\)、\(3\vec{a}\)、\(\vec{a} \cdot \vec{b}\)，并解释每种运算的几何意义。

  2. 矩阵乘法维度分析：如果 \(A \in \mathbb{R}^{3 \times 4}\)，\(B \in \mathbb{R}^{4 \times 5}\)，\(C \in \mathbb{R}^{5 \times 2}\)，那么 \(ABC\) 的维度是什么？计算 \(AB\) 和 \((AB)C\) 的复杂度分别是多少？

  3. 特征值与特征向量计算：求矩阵 \(A = \begin{pmatrix} 3 & 1 \\ 0 & 2 \end{pmatrix}\) 的特征值和对应的特征向量，并验证 \(A\vec{v} = \lambda\vec{v}\) 对每个特征对成立。

  4. SVD 应用思考：考虑一个 100×100 的图像矩阵，如果对其进行 SVD 分解并保留前 10 个奇异值，重构后的矩阵秩是多少？

  5. 范数的比较：对于向量 \(\vec{x} = (1, -2, 3, -4)\)，计算其 L1 范数、L2 范数和 L∞ 范数。

概率与统计#

  1. 贝叶斯定理应用：假设某种癌症的发病率为 0.5%，检测方法的灵敏度为 99%，特异度为 98%。如果某人筛查结果呈阳性，计算他真正患病的概率。

  2. 概率分布计算：假设某网站一天的访问量 X 服从泊松分布，均值为 1000 次。求 P(X = 1000) 和 P(X > 1050)。

  3. 期望与方差的计算：设随机变量 X 服从参数为 p 的伯努利分布，计算 E[X] 和 Var(X)。如果 X₁, X₂, …, Xₙ是 n 个独立同分布的伯努利随机变量，Sₙ = X₁ + … + Xₙ 是什么分布？

  4. 协方差与相关系数：设 X 和 Y 的协方差 Cov(X, Y) = 0.5，Var(X) = 0.01，Var(Y) = 100，计算相关系数并解释其含义。

  5. 偏差-方差分析：考虑回归问题，真实函数为 y = sin(2πx)。比较简单模型（常数预测）和复杂模型（5 阶多项式回归）的偏差和方差。

优化基础#

  1. 梯度下降法验证：设目标函数 \(f(x) = x^4 - 3x^3 + 2\)，使用梯度下降法求解最小值，观察不同学习率下的收敛行为。

  2. 随机梯度下降分析：对于一个有 100 万样本的训练集，比较批量梯度下降和随机梯度下降每次迭代的计算复杂度。

  3. 动量法分析：考虑函数 \(f(x, y) = x^2 + 10y^2\)，使用标准梯度下降和动量法迭代 100 步，比较收敛路径。

  4. Adam 算法实现：实现 Adam 优化器，包括偏差校正步骤，并用其训练一个简单模型。

  5. 约束优化：求解约束优化问题 \(\min_{x, y} x^2 + y^2\) s.t. \(x + y = 1\)，使用拉格朗日乘数法验证结果。
