本章小结#

AI系统基本概念#

AI系统（AI System）是连接硬件和上层应用的中间层软硬件基础设施，是人工智能时代承担类似传统软件栈中数据库、操作系统、中间件角色的关键系统组件。

核心要点：

  • AI系统将复杂的底层硬件抽象隐藏起来，让算法工程师能够专注于算法本身的设计和创新

  • 机器学习是实现AI的方法，深度学习是实现机器学习的技术，神经网络是深度学习的具体实现形态

  • AI发展经历了萌芽期（1950s-1980s）、繁荣期（1980s-2010s）、突破期（2012-2020）和大模型时代（2020-至今）

AI学习基础#

  • 前向传播：数据从输入层经过隐藏层向输出层流动，产生预测结果

  • 反向传播：计算预测值与真实标签之间的误差，将误差反向传播并更新权重

  • 训练：通过迭代计算使损失值Loss越来越小

  • 推理：使用训练好的模型进行预测，只需执行前向传播

主流AI算法#

  • CNN（卷积神经网络）：计算机视觉领域的基础模型结构

  • RNN（循环神经网络）：适合时序数据和自然语言处理

  • GAN（生成对抗网络）：生成模型，用于生成新数据

  • Transformer：大语言模型的基础架构

AI发展驱动力#

  1. 大数据积累：数据驱动方式推动AI算法效果提升

  2. 算力提升：从CPU到GPU再到专用AI芯片，硬件算力大幅提升

  3. 算法突破：从AlexNet到Transformer，模型结构不断创新

AI系统全栈架构#

AI系统全栈架构从上到下分为四个层次：应用层 → AI框架层 → AI编译器层 → 硬件层

各层职责#

层次

主要组件

核心职责

应用层

AI应用、模型服务

业务逻辑、接口封装

AI框架层

PyTorch、MindSpore等

编程接口、自动微分、计算图构建

AI编译器层

TVM、XLA、Glow等

代码生成、优化调度

硬件层

GPU、NPU、TPU等

计算执行、加速运算

AI训练与推理框架#

  • AI框架提供Python API供开发者编写神经网络模型

  • 实现自动微分功能，支持反向传播训练

  • 支持静态图和动态图两种计算图构建方式

  • 提供数据加载、模型管理等工具链

AI编译器#

AI编译器是领域特定编译器，具有四个特征：

  • 基于前端高级语言（如Python）的AST

  • 多层IR设计

  • 面向神经网络优化

  • DSA芯片架构支持

AI硬件#

  • GPU：英伟达主导，广泛应用于AI训练

  • TPU：谷歌专用AI加速器

  • NPU：华为昇腾系列

  • 互联技术：NVLink、RDMA、InfiniBand等

分布式训练#

  • 数据并行：每个设备持有完整模型，处理不同数据

  • 模型并行：将模型分配到不同设备

  • 混合并行：组合多种并行策略
