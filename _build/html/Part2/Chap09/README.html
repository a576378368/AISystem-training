本章小结#

本章围绕AI框架的三大核心功能——自动微分、计算图和分布式训练——进行了系统性的介绍。

自动微分是AI框架的核心功能之一，它解决了深度学习中最关键的梯度计算问题。我们从微分的基本概念出发，详细介绍了手动微分、数值微分、符号微分和自动微分四种方法的优缺点。自动微分通过将复杂的数学函数分解为一系列基本操作的组合，利用链式法则精确计算导数，既保证了数值精度，又避免了表达式膨胀问题。

在前向模式和反向模式的对比中，我们发现反向模式更适合深度学习中的多参数优化场景，因为只需要一次反向传播即可计算出所有参数的梯度。反向模式也是PyTorch、TensorFlow等主流AI框架采用的自动微分实现方式。

计算图是AI框架表达神经网络计算的核心数据结构。通过计算图，框架可以将复杂的神经网络模型表示为一系列节点（算子）和边（张量）的有向无环图。计算图不仅支持自动微分，还能进行图优化、算子融合、内存优化等多种优化操作。

静态图和动态图是两种主要的计算图执行模式。动态图（如PyTorch）灵活易用，适合研究开发；静态图（如TensorFlow）执行效率高，适合部署推理。现代AI框架通过JIT编译等技术，正在实现动静统一，兼顾灵活性和效率。

分布式训练解决了大模型训练的计算资源和内存需求问题。我们介绍了数据并行（DP/DDP）、模型并行（张量并行、流水线并行）和混合并行等多种分布式训练策略。

数据并行通过复制模型到多个设备处理不同数据批次来加速训练，是最常用的并行方式。DDP通过Ring AllReduce和计算通信重叠等优化，实现了高效的数据并行训练。FSDP通过ZeRO技术分片模型状态，进一步降低了单设备的内存占用。

张量并行将单层参数切分到多个设备，流水线并行将不同层分配到不同设备，两者可以组合使用，应对超大模型的训练需求。3D混合并行结合数据并行、张量并行和流水线并行的优势，是当前大模型训练的主流方案。

思考与练习#

  1. 自动微分的核心原理是什么？为什么反向模式更适合深度学习训练？

  2. 计算图中节点和边分别代表什么？如何理解计算图的拓扑顺序？

  3. 动态计算图和静态计算图各有什么优缺点？现代AI框架如何实现动静统一？

  4. 数据并行和模型并行的区别是什么？它们分别适合什么场景？

  5. ZeRO优化的三个阶段分别解决了什么问题？为什么FSDP能支持超大模型训练？

  6. 什么是流水线并行中的”气泡”问题？有哪些方法可以减少气泡提高效率？

  7. 混合并行为什么是大模型训练的主流方案？DP、PP、TP各自的作用是什么？
