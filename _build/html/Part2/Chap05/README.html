本章小结#

本章系统介绍了神经网络的基础知识与主流模型结构。

神经元与网络模型章节介绍了神经网络的基本组成组件，包括神经元、激活函数、网络层数、前向传播、反向传播、损失函数和优化算法等核心概念。重点讲解了全连接层的权重求和计算范式，这是神经网络最核心的计算操作。

卷积神经网络章节详细阐述了卷积层的工作原理，包括卷积操作、特征图、池化等关键概念。同时介绍了从LeNet到ResNet的经典CNN架构演进，以及深度可分离卷积等轻量化技术。

循环神经网络章节介绍了RNN的基本原理和训练挑战，重点讲解了LSTM和GRU等改进模型如何通过门控机制解决梯度消失问题，实现长期依赖的学习。

Transformer与注意力机制章节深入分析了自注意力机制和多头注意力的计算原理，以及Transformer的整体架构。Transformer通过纯注意力机制实现了序列处理的并行化，成为现代大语言模型的基础架构。

模型量化基础章节介绍了量化的基本概念、方法和数据类型。重点讲解了对称/非对称量化、MinMax/KL散度等量化算法，以及FP32、FP16、BF16、FP8、INT8等数据类型，为模型压缩和AI芯片设计提供了理论基础。

思考与练习#

  1. 神经元计算：分析神经元模型中MAC运算的特点，及其对AI芯片架构的影响。

  2. 卷积优化：比较卷积神经网络中不同卷积优化技术（如Im2Col、Winograd）的优缺点。

  3. 长距离依赖：比较RNN（LSTM）和Transformer在处理长距离依赖问题上的方案差异。

  4. 注意力机制：分析多头注意力相比单头注意力的优势，以及注意力机制对硬件的挑战。

  5. 模型量化：设计一个量化感知训练方案，说明如何在训练过程中模拟量化效果。

本章总结#

通过本章学习，应掌握：

  • 神经网络的基本计算单元和训练推理流程

  • CNN、RNN、Transformer三大主流网络结构

  • 模型量化的基本概念和方法

  • 理解AI芯片需要支持的计算模式和精度需求
