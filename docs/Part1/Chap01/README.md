3. 了解程序运行的基本原理

## 本章小结

本章为计算机基础预备知识章节，共包含三个部分：

**第一部分：进制与编码**
- 介绍了二进制、八进制、十六进制的基本概念和相互转换方法
- 详细讲解了原码、反码、补码的原理，以及计算机如何用补码表示有符号整数
- 解释了IEEE 754浮点数标准，包括规格化数、非规格化数和特殊值
- 介绍了ASCII和UTF-8字符编码的原理

**第二部分：CPU与内存**
- 阐述了冯诺依曼架构的基本原理和五大组成部分
- 深入分析了CPU的结构：ALU、控制单元、寄存器和指令执行流程
- 讲解了内存层次结构：寄存器、高速缓存、主存、虚拟内存的工作原理
- 介绍了局部性原理（时间局部性和空间局部性）是缓存技术的基础
- 说明了总线、DMA、缓存一致性和中断机制等CPU与内存交互的关键概念

**第三部分：程序运行原理**
- 描述了从源代码到可执行程序的完整过程：预处理、编译、汇编、链接
- 解释了ELF可执行文件格式的结构和程序的内存布局
- 深入讲解了进程与线程的概念、区别和同步机制
- 分析了并发与并行的区别，以及并发编程面临的问题（竞态条件、死锁等）
- 介绍了操作系统在内核态与用户态的角色，以及系统调用的工作机制

## 思考与练习

1. **进制转换与编码**
   - 将二进制数 $1101011_2$ 转换为十进制、八进制和十六进制。
   - 为什么计算机使用补码而不是原码来表示有符号整数？
   - 解释浮点数精度问题：为什么 `0.1 + 0.2 != 0.3` 在大多数编程语言中成立？

2. **CPU与内存**
   - 描述冯诺依曼架构的基本工作流程，解释什么是"冯诺依曼瓶颈"。
   - 假设L1 Cache未命中，CPU接下来会检查哪里？请描述缓存逐级查找的过程。
   - 什么是虚拟内存？它解决了哪些问题？

3. **进程与线程**
   - fork()系统调用有什么特殊之处？为什么它返回两次？
   - 多线程程序中，为什么需要互斥锁来保护共享数据？请分析如果不加保护会发生什么问题。
   - 线程与进程的根本区别是什么？

4. **并发与并行**
   - 并发（Concurrency）和并行（Parallelism）的区别是什么？请各举一个实际应用场景。
   - 什么是死锁？死锁产生的四个必要条件是什么？如何避免死锁？
   - 如果程序中有90%的代码可以并行化，使用8核处理器，理论最大加速比是多少？（根据Amdahl定律计算）

5. **系统调用与程序运行**
   - 为什么用户程序不能直接访问硬件？系统调用是如何实现用户态和内核态切换的？
   - 描述在Linux终端执行 `./a.out` 时，从shell创建进程到程序运行的完整过程。
   - 静态链接和动态链接各有什么优缺点？
